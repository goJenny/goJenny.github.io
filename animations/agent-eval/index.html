Benchmarking Your Own Workload
우리 업무로 직접 평가하는 5단계
1
공개 기준선 확보Public floor

공개 에이전트 벤치마크를 실행하고, 3~5회 성공률 범위를 기록합니다.

2
도메인 평가 구축Domain eval

실제 티켓·트레이스·API로 구성합니다. 판정 기준은 DB 행, 병합된 PR, 종료된 티켓 같은 환경 상태입니다.

3
모델·하네스 적응Adapt

모델과 실행 환경을 해당 업무 분포에 맞게 조정합니다.

4
재측정Re-measure

성공률, 일관성, 성공당 단계 수, 성공당 비용을 다시 측정하고 단계 기록을 보관합니다.

5
결과 검증Verify

결과는 환경에서, 언어 품질은 심판 모델로, 끊긴 지점은 정밀도·인자 정확도로 확인합니다.
